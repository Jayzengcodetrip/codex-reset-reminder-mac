Codex 重置提醒 v0.2.2 更新了临时预告的展示循环，并识别两种官方发放方式：直接重置额度（one-time reset）和发放重置券（banked reset）。

- 只有日期的预告仍分两段倒计时：先等洛杉矶预告日开始，再倒数该日剩余时间。明确钟点的预告按明确时刻倒数。
- 官方宣布已开始直接重置或发券，并能关联到对应预告时，就结束该条倒计时。没有其他有效预告时，当天显示“暂无最新重置预告（今天已重置）”。这里表示官方已宣布开始发放，不保证每个账户已到账。
- 洛杉矶当天结束后，显示“暂无最新重置预告（距离上次重置已过…）”，每秒更新。不足一天使用 `00:04:31`，满一天使用 `1天00:06:31`。累计从最近已知的普遍发放时间计算，不从预告截止或本机检查时间计算；没有可靠记录时不虚构累计时间。
- 预告当天过去仍未发放，顶部收起过期倒计时，未确认记录继续保留在历史中。两条预告独立处理；账户额度刷新、券数变化、读过公告均不作为发放证据。
- 发放证据由 [Codex Resets](https://codex-resets.com/) 官方原帖全文与 [NextReset.org](https://nextreset.org/) 事件关联补充，[NextReset](https://nextreset.net/) 继续提供预告。优先使用明确关联；无明确关联时，只匹配同一洛杉矶目标日、类型相容且唯一的官方预告，并在详情中说明匹配依据。定向补偿不会当作普遍重置。
- 修复接口降级时重复通知、迟到预告抢占已有发放关系、时间修订被旧日期错误关闭以及跨午夜窗口高度未更新的问题。

洛杉矶是应用采用的参考时区，不是官方指定的重置时区。两段日期倒计时都只是日历估算，不建议仅凭预告清空额度。第三方来源和网络可能延迟，不能保证原帖发布五分钟内收到提醒。

安装适用于 Apple Silicon Mac，macOS 14 或更新版本。下载 DMG，把 `CodexNotch.app` 拖到“应用程序”，先退出旧版再打开新版。ZIP 为备用格式。安装包使用 ad-hoc 签名，未经 Apple Developer ID 签名和公证。公告账本继续保留在 `~/Documents/Codex/QuotaReminderState/announcements.json`。公开数据请求不发送 Codex 账户凭据。

本机验证包括重置行为自检、跨窗口策略检查、公开接口读取、合成测试以及 8 种真实 SwiftUI 组件的离屏布局。仅命令行开发工具的本机环境没有 XCTest；对应核心测试用独立断言程序执行，GitHub 构建另外执行完整 XCTest。离屏和策略检查不能替代所有屏幕、全屏应用、睡眠唤醒或全新机器的实际验证。
