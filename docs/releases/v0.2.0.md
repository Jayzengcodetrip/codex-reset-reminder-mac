这是 Codex 重置提醒的首个公开安装包，基于 [fengdwx/codex-notch](https://github.com/fengdwx/codex-notch) v0.1.16（MIT）制作，由 Jayzengcodetrip 独立维护。

新增临时重置预告与倒计时、公告历史、醒来后补查、每周额度倒计时和账户重置券显示；悬浮窗支持在其他应用前显示，隐藏后可从屏幕顶部悬停唤出。公告取自第三方 [NextReset](https://nextreset.net/)，不是 X 官方实时接口；来源延迟、缺失或改版时，提醒也可能延迟或不可用。

**安装**：Apple Silicon Mac、macOS 14 或更新版本。优先下载下方 `CodexNotch-0.2.0-macOS-arm64.dmg`，打开后将应用拖到“应用程序”。ZIP 是备用格式。此版本使用 ad-hoc 签名，未经 Apple 公证；首次运行时如 macOS 阻止，请在“系统设置 → 隐私与安全性”中确认“仍要打开”。具体步骤见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

应用需要本机已登录 Codex / ChatGPT，才能读取该账户的额度与重置券。不会把 Codex 凭据发送给 NextReset；详情见仓库 README。DMG、ZIP 对应的 `.sha256` 文件可用于核对下载完整性。

若 Mac 上仍运行原版 CodexNotch 或此前的本地定制版，请先退出旧应用，避免重复提醒。本版使用独立应用标识，显示偏好与登录项可能需要重新设置。
