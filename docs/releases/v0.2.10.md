Codex 重置提醒 v0.2.10 新增人工确认重置完成，方便自动识别暂未跟上时直接结束预告。

- 在预告时间旁新增“确认已重置”，点击后仅完成对应原帖的预告，距上次重置从点击时刻重新计时，标明人工确认来源。
- 无日期或已离开首页的待定预告，可在公告历史详情里单独确认；历史保留原文和人工确认时间，并提供“撤销人工确认”。
- 保存成功后才更新界面；失败时保留原状态并提示。重复点击、重启、刷新、同帖别名和在途请求不会重新开启已人工完成的预告，也不会重置确认时间。
- 同一事件晚到的官方完成消息不会再次移动人工计时；独立的新重置继续按原规则处理。人工操作不清除未读、不弹出公告通知，不改写官方完成证据。
- 原有官方消息识别、账户额度恢复识别、周额度与重置券展示保留。此功能不会执行账户重置或兑换重置券。

安装：下载 Apple Silicon 的 DMG，将 CodexNotch 拖到“应用程序”；ZIP 为同一应用的压缩包。macOS 14+。应用采用临时签名，未做 Apple 公证；首次打开请按 README 的“隐私与安全性 → 仍要打开”说明操作，不要关闭系统安全功能。
