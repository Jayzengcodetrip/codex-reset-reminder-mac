**Codex 重置提醒 v0.2.18（构建 38）** 把顶部小窗改成了活跃预告看板。从上个公开版 v0.2.15 升级，也会获得后台耗电相关的优化和「重置动态」窗口修复。

- **一眼看到待处理的预告。** 小窗收起时，橙色圆点表示首页还有活跃预告。「重置动态」可按「全部」和「待定」查看，已移除已读和未读操作。
- **每张卡只显示一个计时。** 有明确日期或钟点的预告显示倒计时。无日期预告合并为摘要，显示原帖摘录；原帖发布时间可确认且已到时，显示「预告已发出」多久。
- **可以单独收起预告。** 点击「收起」后，卡片从首页和「待定」中移除，下方「距上次重置」计时继续。打开「重置动态 → 全部」，可在详情中点「恢复到首页」。
- **更容易发现检查失败。** 首页和「重置动态」用红字显示接口错误。打开预告卡片时，历史窗口会来到当前桌面。小窗收起且空闲时减少后台 CPU 占用。

**下载与安装**

适用于配备 Apple Silicon（M 系列芯片）、运行 macOS 14 或更新系统的 Mac。下载 `CodexNotch-0.2.18-macOS-arm64.dmg`，打开后把 `CodexNotch.app` 拖入「应用程序」。也可下载同版 ZIP。升级时先退出旧版，再替换 App，原有历史和设置会继续使用。

安装包采用 ad-hoc 签名，尚未经过 Apple 公证。首次打开遇到系统提示时，请参阅[中文安装说明](https://github.com/Jayzengcodetrip/codex-reset-reminder-mac/blob/v0.2.18/README.zh-CN.md#安装)。两种安装包均附有 SHA-256 校验文件。
