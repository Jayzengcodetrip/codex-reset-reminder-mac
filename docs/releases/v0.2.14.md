**下载与安装**

适用于 macOS 14 及以上、Apple Silicon（M 系列芯片）Mac。下载 `CodexNotch-0.2.14-macOS-arm64.dmg`，打开后将应用拖入“应用程序”；ZIP 为备用。升级前先退出旧版，原有记录和设置会保留。`Source code` 是开发源码，不是安装包。

安装包使用 ad-hoc 签名，尚未经过 Apple Developer ID 签名及公证。首次打开方法见仓库 README。
