Codex 重置提醒 v0.2.15：调度中心临时隐藏顶部提醒。

- 调整为 macOS 原生窗口规则，由系统在调度中心临时隐藏小窗，解决展开卡片覆盖桌面和全屏软件缩略图的问题。

**下载与安装**

适用于 macOS 14 及以上、Apple Silicon（M 系列芯片）Mac。下载 `CodexNotch-0.2.15-macOS-arm64.dmg`，打开后将 `CodexNotch.app` 拖入“应用程序”；同版 ZIP 为备用。升级前先退出旧版，原有记录和设置会保留。`Source code` 是开发源码，不是安装包。

安装包使用 ad-hoc 签名，尚未经过 Apple Developer ID 签名及公证。首次打开方法见 [中文 README](https://github.com/Jayzengcodetrip/codex-reset-reminder-mac/blob/v0.2.15/README.zh-CN.md#安装)。
